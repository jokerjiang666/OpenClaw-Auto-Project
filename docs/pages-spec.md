### 1.2 组件规格

#### Navbar (导航栏)

| 属性 | 值 |
|------|-----|
| **高度** | 64px (Fixed) |
| **背景** | `rgba(10, 10, 15, 0.8)` + `backdrop-filter: blur(12px)` |
| **边框** | `1px solid rgba(255, 255, 255, 0.08)` (底部) |
| **Logo** | 40px 高度，左侧 |
| **导航项** | 间距 24px，Hover 时文字变 #00FFAA |
| **右侧操作** | 通知图标、头像下拉 |

**交互状态**:
- Scroll > 20px: 添加阴影 `shadow-lg`
- Hover 导航项: 文字颜色 #00FFAA + 下划线动画

#### Hero Section

| 属性 | 值 |
|------|-----|
| **内边距** | 80px 24px |
| **标题** | 48px / 700 / #E2E8F0 |
| **副标题** | 18px / 400 / #94A3B8 / mt-4 |
| **搜索框** | 宽度 400px (Mobile: 100%) |
| **CTA 按钮** | Primary Button 样式 |

**动画**:
- 标题: `fade-in-up` 300ms
- 搜索框: `fade-in-up` 400ms (delay 100ms)
- CTA 按钮：`fade-in-up` 500ms (delay 200ms)

#### Category Card (板块卡片)

```vue
<template>
  <div class="category-card">
    <div class="icon">{{ icon }}</div>
    <h3 class="name">{{ name }}</h3>
    <p class="description">{{ description }}</p>
    <div class="meta">
      <span>{{ posts }} 帖子</span>
      <span>{{ members }} 成员</span>
    </div>
  </div>
</template>
```

| 属性 | 值 |
|------|-----|
| **尺寸** | 280×140px |
| **背景** | `rgba(19, 19, 26, 0.6)` |
| **边框** | `1px solid rgba(45, 45, 58, 0.5)` |
| **圆角** | 12px |
| **内边距** | 20px |
| **图标** | 48px，主色渐变 |

**6 态定义**:
| 状态 | 背景 | 边框 | 阴影 | 变换 |
|------|------|------|------|------|
| Default | rgba(19, 19, 26, 0.6) | #2D2D3A | none | none |
| Hover | rgba(26, 26, 36, 0.8) | #00FFAA40 | glow-primary | translateY(-4px) |
| Active | rgba(26, 26, 36, 1) | #00FFAA | glow-primary-intense | translateY(-2px) |
| Focus | rgba(19, 19, 26, 0.6) | 2px #00FFAA | glow-primary | none |
| Disabled | rgba(19, 19, 26, 0.3) | #2D2D3A | none | none |
| Loading | rgba(19, 19, 26, 0.6) | #2D2D3A | none | shimmer |

#### Post Card (帖子卡片)

| 属性 | 值 |
|------|-----|
| **高度** | 120px (固定) |
| **布局** | Flex row (图标 + 内容 + 元数据) |
| **标题** | 16px / 600 / #E2E8F0 |
| **摘要** | 14px / 400 / #94A3B8 / 2 行截断 |
| **元数据** | 12px / #64748B |
